# 똑비서 (DdokBiseo)

> 내 기기에만 저장되는 일정·할일 관리 앱

---

## 소개

똑비서는 할일, 반복 일정, 주간 할일, 창고(보관함), 습관 트래커, 디데이,
버킷리스트를 한곳에서 관리하는 웹 앱입니다.

- **모바일**: `index.html`
- **PC**: `index-pc.html`

회원가입이나 로그인 없이 바로 사용할 수 있습니다.

---

## 데이터 저장 방식

- 모든 데이터는 **사용 중인 기기의 브라우저 안에만** 저장됩니다.
- 서버로 전송되거나 다른 곳에 보관되지 않습니다.
- 기기나 브라우저가 다르면 데이터도 따로 저장됩니다. (자동 동기화 없음)

### ⚠️ 꼭 백업하세요

다음과 같은 경우 데이터가 사라질 수 있습니다.

- 브라우저의 "인터넷 사용 기록 / 사이트 데이터 삭제"
- 기기 초기화, 변경, 분실
- 일부 브라우저(특히 iPhone Safari)에서 오랫동안 앱을 열지 않은 경우

**설정 → 💾 백업 내보내기**로 백업 파일을 정기적으로 저장해 두세요.

---

## 백업과 복원

| 메뉴 | 설명 |
|---|---|
| 💾 백업 내보내기 | 할일·반복·창고·습관·디데이·버킷리스트·테마 설정을 모두 담은 파일(`ddokbiseo_backup_날짜_시각.json`)을 저장합니다. |
| 📂 백업 불러오기 | 백업 파일을 선택하면 **현재 데이터를 모두 지우고** 백업 당시 상태로 그대로 복원합니다. |

백업 파일을 다른 기기에서 불러오면 같은 데이터를 옮겨 쓸 수 있습니다.
